## Risks or blockers

- World saves and SQL are not atomic. Journals are replayable, but an uncommitted observation whose world/authority/bounds no longer matches fails closed and retains its journal. Resolve inconsistent backups/authority deliberately; never suppress the error or delete journals to advertise successful recovery.
- Geometry is a bounded block-grid interpretation: explicit portals/narrow passages and vertical contacts, not full structural physics or a perfect room/opening solver. The raw snapshot remains available for later safe analysis; future changes to its interpretation/encoding need explicit version policy.
- Ordinary operational/unattributed world changes and external plugin/console edits are not automatically adopted as player design. Explicit authorized resize/rescan can capture current design; future Decay/Repair must not call that path to overwrite intended baselines.
- No native-client visual sign-off was claimed; new Building UI is command-based. Existing Management Book visual checks remain pending.
- Isolated fixtures retain their prior 0.3 Local Activity test threshold; shipped default remains 20. Do not copy test tuning or QA artifacts into user deployment.
